## Anti-scope-creep rules

If a task requests a future feature:
1. check whether it is needed for the golden path
2. if not, do not implement it automatically
3. mark it as future/TBD
4. continue with the current P0 task

## Demo boundary

The competition demo may conceptually explain:
Verification → Registry → Issuance → Trading → Farmer Benefit

But the product must not claim these actions actually occur in MVP.
